Flashcard Study App (Ứng Dụng Ôn Tập Flashcard)

Ứng dụng web ôn tập flashcard đơn giản, thân thiện và hiện đại. Người dùng có thể dễ dàng tải lên các file định dạng .txt chứa bộ câu hỏi để bắt đầu học và ghi nhớ kiến thức nhanh chóng.

🚀 Tính năng nổi bật

Tải bộ câu hỏi từ file TXT: Tự động lấy tên file làm tiêu đề bài học.

Phân loại theo Chương: Lọc câu hỏi theo từng chương hoặc học toàn bộ.

Hiệu ứng lật thẻ (Fade & Color Transition): Hiệu ứng làm mờ mịn màng và đổi màu nền khi lật sang đáp án giúp tăng khả năng tập trung.

Điều hướng dễ dàng: Hỗ trợ xem câu tiếp theo, câu trước đó, và làm lại từ đầu.

Thanh tiến trình (Progress Bar): Theo dõi trực quan tỉ lệ hoàn thành bài học.

Giao diện Responsive: Tối ưu hóa trên cả máy tính và thiết bị di động.

📝 Định dạng File .txt Đầu Vào

Dữ liệu câu hỏi được phân cách tự động dựa trên 1 dòng trống giữa các câu. Bạn có thể định nghĩa chương bằng cách đặt tên chương ở đầu dòng (bắt đầu bằng Chương hoặc Chuong).

Ví dụ mẫu:

Chương 1
HTML viết tắt của từ gì?
HyperText Markup Language

CSS dùng để làm gì?
CSS dùng để định dạng và tạo kiểu dáng cho trang web.

Chương 2
JavaScript là ngôn ngữ gì?
JavaScript là ngôn ngữ lập trình kịch bản được sử dụng rộng rãi trên web.


👨‍💻 Công nghệ sử dụng

HTML5 & CSS3 (Đặt tên Class chuẩn BEM).

JavaScript (Vanilla JS): Sử dụng FileReader API xử lý đọc file phía Client.

FontAwesome: Hệ thống icon trực quan.
